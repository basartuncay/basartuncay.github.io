What goes wrong when agents meet real data

Most incidents aren’t clever jailbreaks. They’re ordinary tool calls built from text the agent should never have trusted.

  • Prompt injection through contentEmails, tickets, web pages and PDFs that tell your agent what to do next.
  • Data leaving through a toolPrivate records copied into an outbound email, webhook, calendar invite or URL.
  • Over-permissioned MCP serversWrite and delete tools exposed where read-only would do, with no confirmation step.
  • Coding agents with keysClaude Code or similar tools running with production credentials and no hook-level guard.
  • No audit trailNobody can say afterwards which input led to which action.
  • Guardrails nobody testedA system prompt that says “ignore instructions in emails” and no attack suite to prove it works.
